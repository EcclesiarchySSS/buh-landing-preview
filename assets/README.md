# Изображения и шрифты сайта

## Шрифты

`fonts/` — self-hosted variable-шрифты, подключены в `css/styles.css` через `@font-face`:

- `golos-text-*.woff2` — Golos Text 400–800, основной текст;
- `jetbrains-mono-*.woff2` — JetBrains Mono 400–700, служебные подписи «ведомости».

Подмножества: кириллица + латиница. Хранятся локально намеренно: без обращений
к серверам Google Fonts (152-ФЗ) и быстрее. Менять не нужно.

## Фото

| Файл | Где | Статус |
|---|---|---|
| `img/auditor.jpg` (720×900) + `img/auditor-400.jpg` | hero, портрет 4:5 | ✅ есть (селфи от 2026-09-10, кадр 01) |
| `img/diplom-*.jpg` | «Почему нам доверяют» → приложения П-1…П-3 | ⏳ ждём сканы от заказчицы |

Фото офиса/команды **не будет** (сказала заказчица) — слоты под них убраны.

## Как подключить дипломы, когда придут

1. Сжать: длинная сторона ~1200 px, JPEG q≈82 (в `backend/.venv` есть Pillow).
2. Положить в `img/diplom-1.jpg`, `img/diplom-2.jpg`, …
3. В `index.html` (блок `.docs`) заменить `<figcaption>` внутри `.photo-slot` на
   `<img src="assets/img/diplom-1.jpg" alt="Диплом о …" loading="lazy">`.
   Скан встаёт целиком (`object-fit: contain`), любая ориентация подходит.
4. Лишние слоты удалить, если документов меньше трёх.
